# TISSO VISION – Shopify Theme

A custom Shopify theme implementation built on top of the Dawn theme as the base.

## Features

- Custom responsive banner section
- Custom product grid with six product-picker blocks
- Dynamic product information using Shopify product data
- Product variant selection
- Animated color selector
- Dynamic product pricing and images
- Add to Cart using Shopify Cart API
- Automatically adds the Soft Winter Jacket when Black + Medium is selected
- Cart drawer and cart count update without page refresh
- Product modal with:
  - Close button
  - Outside-click close
  - Escape-key close
- Responsive desktop, tablet, and mobile layouts

## Technologies

- Shopify Liquid
- HTML
- CSS
- Vanilla JavaScript
- Shopify Ajax Cart API
- Dawn theme as the base theme
